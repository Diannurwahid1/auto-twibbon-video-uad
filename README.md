# p2ktools-autoeditor

Tools Auto Editor Twibbon Prakarsa UAD 2026.

## Analytics & Impact

Project ini dibuat untuk membantu maba UAD membuat Twibbon Video P2K Prakarsa
2026 tanpa perlu edit manual di CapCut. Dalam masa awal penggunaan, tools ini
mulai dipakai oleh banyak mahasiswa baru untuk upload foto, atur frame,
generate video HD, dan menyiapkan caption sesuai format P2K.

![Analytics impact Twibbon P2K Prakarsa UAD 2026](docs/analytics-impact.png)

Ringkasan analytics per 8 September 2026:

- 2,112 visitors
- 4,625 page views
- 61% bounce rate
- 1 online user pada saat screenshot diambil

Impact utama:

- Mempermudah mahasiswa baru membuat video twibbon dengan satu halaman web.
- Mengurangi kebutuhan edit manual menggunakan aplikasi eksternal.
- Menjaga proses upload foto tetap diproses di browser pengguna.
- Menyediakan caption siap copy sesuai format publikasi P2K.
